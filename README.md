# SY09 - Projet d'analyse de données

Projet réalisé dans le cadre du cours SY09 (Analyse de données) de l'UTC, portant sur plusieurs méthodes d'analyse statistique et d'apprentissage non supervisé/supervisé.

## Contenu

- `source/` : notebooks et scripts Python
  - Exploration et visualisation des données (`Exploration.ipynb`, `Viz.ipynb`, `Vizualisation.py`)
  - Analyse en composantes principales, AFTD et classification ascendante hiérarchique (`PCA_AFTD_CAH.ipynb`)
  - Clustering k-means / k-means++ (`K-means.ipynb`, `Kpp.ipynb`, `Kpp_clean.ipynb`)
  - Analyse discriminante (`analyse_discriminante.ipynb`)
  - Régression linéaire et logistique (`regression_lineaire.ipynb`, `Regerssion/shapiro.ipynb`)
  - Fonctions utilitaires de TD (`td_functions/`) : KNN, Bayes, validation croisée, prototypes, recherche stochastique
  - Réponses aux questions du projet (`reponses_questions.ipynb`)
- `projet/` : rapport final (`projet.pdf`, source LaTeX `projet.tex`) et figures associées
- `subject/` : sujet du projet distribué par l'enseignant (`projet.pdf`)

## Contexte

Projet de groupe réalisé pour le cours SY09 à l'UTC.
